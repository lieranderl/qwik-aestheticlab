# Qwik Aesthetic Lab

A small playground for experimenting with design systems, visual aesthetics, and performant UI patterns using Qwik.

## Features
- Component-driven visual experiments
- Design token playground (colors, typography, spacing)
- Hot-reload development for quick iteration
- Production-ready build for static deployment

## Quick start

Prerequisites: Node.js 18+ and your preferred package manager (npm, pnpm, yarn).

Install dependencies:
```bash
npm install
# or
pnpm install
# or
yarn
```

Run the dev server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Useful scripts
- `dev` — start development server with HMR
- `build` — produce production output
- `preview` — locally preview the built app
- `lint` — run linters (if configured)
- `test` — run tests (if configured)

## Project structure
- `src/` — application source (components, routes, styles)
- `public/` — static assets
- `build/` or `dist/` — production output (generated)
- `README.md` — this file
- `package.json` — scripts & dependencies
